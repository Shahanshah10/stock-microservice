## Overview
stock-microservice - This service is responsible for processing stock (save, update,retrieval, delete) using the Rest API approach and retrieving stock based on currency using GraphQL.  
## Dependencies 
 stock-util --[Learn more about the project here] (https://github.com/Shahanshah10/stock-util)  -- To achieve the OpenAPI approach and make data transfer objects definitions.
 Spring-boot-starter-data-cassandra - Using NoSQL DB `Cassandra` for doing all the db operations.
 Spring-boot-starter-actuator - To check the health of the service.
 Mapstruct dependencies to do mapping from one class to another class.
